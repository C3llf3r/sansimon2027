# Caporales San Simón Sucre - Convocatoria 2K27

Landing page oficial para la **Convocatoria 2K27** de Caporales Universitarios San Simón Sucre.

🌐 **Enlace oficial:** [https://sansimon.nerosystem.solutions](https://sansimon.nerosystem.solutions)

---

## 🚀 Tecnologías

- **React 19**
- **Vite 8**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Framer Motion**
- **Lucide React**
- **Oxlint**

---

## 🛠️ Desarrollo Local

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar servidor de desarrollo:
   ```bash
   npm run dev
   ```

3. Construir para producción:
   ```bash
   npm run build
   ```

4. Ejecutar linter:
   ```bash
   npm run lint
   ```

---

## 📋 Estructura

- `src/App.jsx`: Componente principal con Navbar, Video Hero interactivo y Modal de registro con integración directa a WhatsApp.
- `src/index.css`: Estilos globales, tipografías personalizadas (`Varsity Team`, `Cinzel`) y tokens del tema.
- `public/`: Recursos multimedia (`icono.png`, `logo.mp4`, fuentes).
